# 横向周历与今日放送图片设计

## 目标

将 `/番剧 本周` 改为一张横向周历 PNG：列顺序固定为周日到周六，七列等宽，节目按各自放送时间由早到晚排列。每个日期列顶部对齐，列的视觉高度只由当天节目数决定；番名保持单行并以省略号截断。

将 `/番剧 今天 [YYYY-MM-DD]` 改为同一视觉语言的单日 PNG：已知时间升序显示，待定时间归入底部独立区块。两条命令保留原有文字作为空结果和绘制异常时的回退。

## 边界

- 不变更数据源、NSFW 过滤、群时区、订阅或推送逻辑。
- 周表范围改为当地周日零点至下周日零点；图片列顺序与查询范围一致。
- 不使用远程封面或新增常驻服务；所有图片均在本地缓存目录生成。

## 模块与数据流

`ScheduleImageRenderer` 是唯一的绘制与缓存入口，提供 `render_weekly_cached()` 和 `render_daily_cached()` 两个方法。二者共享字体预检、缓存原子写入、指纹和配色，布局绘制保持独立。

缓存位于 `CARD_ASSET_ROOT/schedules/weekly/` 与 `CARD_ASSET_ROOT/schedules/daily/`。指纹包含布局版本、日期范围或目标日期、群时区、番剧 ID、标题、放送时间和集数，避免旧版竖向图片命中新版缓存。

AstrBot 的 `ScheduleReplyFactory` 提供 `build_weekly()` 和 `build_today()`。`EventAdapter` 在得到原有文字回复后，仅对有条目的 `WEEK`/`TODAY` 结果尝试构图；今日路径明确传入用户指定的日期，保证 `/番剧 今天 YYYY-MM-DD` 不会误标为当前日期。

## 版式与可读性

- 周历画布宽 1680px；外边距与列间距固定，七日列使用相同宽度。
- 周列固定显示周日到周六，即使当天无节目也保留表头；节目少的列不填充到最高列底部。
- 单节目卡显示时间、单行省略标题、集数胶囊；同日的 `待定` 固定排到已知时间之后。
- 今日卡为单列时间表，含日期、星期、已知时间区块、待定区块和条目总数。
- 图片过密到无法在最大高度中完整显示时视为绘制失败并回退文字，绝不裁掉条目。

## 容错与验证

- 无数据不创建图片，返回当前文字结果。
- 字体、文件或 PIL 绘制异常记录结构化警告并回退文字。
- 单元测试覆盖 PNG 尺寸、缓存命中、七日列、单行截断、今日待定排序、空结果与渲染失败回退。
- AstrBot 适配测试覆盖 `/番剧 本周` 和带/不带日期的 `/番剧 今天` 返回单张图片；现有文本断言继续覆盖回退。

## 发布

本地测试通过后，分支快进到远端 `main`，推送触发 ACR `latest` 构建。确认 digest 更新后运行服务器的 `sudo /opt/anime-qqbot/scripts/deploy-acr.sh`。该流程备份数据库并重建 Worker/AstrBot，NapCat 保持不重启；部署健康不替代真实 QQ 群图片展示验收。
